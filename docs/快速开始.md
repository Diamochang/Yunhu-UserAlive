# 快速开始指南

## 🚀 3 步快速启动

### 1️⃣ 复制配置文件

```bash
cp config_local.py.example config.py
```

### 2️⃣ 运行初始化

```bash
python init.py
```

初始化向导会引导你完成：
- ✅ 配置验证
- ✅ 数据库创建
- ✅ 云湖账户配置
- ✅ 自动生成安全密钥（可选）

### 3️⃣ 启动应用

```bash
# 本地开发
python app.py

# 访问控制台
open http://localhost:5000
```

## 📝 配置说明

所有配置都在 `config.py` 文件中，分为以下部分：

### 必需配置（修改后首次启动生效）

```python
# 加密配置（首次设置后不要修改！）
MASTER_PASSWORD = "your-secure-password-at-least-8-chars"
ENCRYPTION_SALT = "your-random-salt"
FLASK_SECRET_KEY = "your-flask-secret"
```

**生成安全密钥**:
```bash
# 生成 MASTER_PASSWORD
python -c "import secrets; print(secrets.token_urlsafe(16))"

# 生成 ENCRYPTION_SALT
python -c "import secrets; print(secrets.token_hex(16))"

# 生成 FLASK_SECRET_KEY
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

### 部署环境

```python
# 本地开发
DEPLOYMENT_ENV = "local"

# PythonAnywhere 部署
DEPLOYMENT_ENV = "pythonanywhere"
```

**注意**: 切换到 `pythonanywhere` 时，系统会自动：
- 使用绝对路径
- 调整数据库和日志路径

### 云湖账户（可选配置）

```python
# 方式一: 在配置文件中设置
YUNHU_EMAIL = "your-email@example.com"
YUNHU_PASSWORD = "your-password"
DEVICE_ID = ""  # 留空自动生成

# 方式二: 运行 init.py 时通过命令行输入（推荐）
# 这样密码不会明文保存在配置文件中
```

## 🔐 安全建议

### 1. 配置文件安全

```bash
# 设置文件权限（仅所有者可读写）
chmod 600 config.py

# 添加到 .gitignore（不要提交到仓库）
echo "config.py" >> .gitignore
```

### 2. 使用强密码

- `MASTER_PASSWORD`: 至少 16 字符
- `ENCRYPTION_SALT`: 32 字符十六进制
- `FLASK_SECRET_KEY`: 32 字符随机字符串

### 3. 不要修改已有数据

⚠️ **警告**: 修改 `MASTER_PASSWORD` 或 `ENCRYPTION_SALT` 后：
- 无法解密已存储的邮箱和密码
- 需要重新添加用户

### 4. 定期备份

```bash
# 备份数据库
cp data/yunhu_useralive.db backup/yunhu_useralive_$(date +%Y%m%d).db

# 备份配置文件
cp config.py backup/config_$(date +%Y%m%d).py
```

## 🐛 常见问题

### Q1: 初始化失败

**错误**: `配置验证失败`

**解决**:
1. 检查 `config.py` 是否存在
2. 确认必需的配置项已设置
3. `MASTER_PASSWORD` 至少 8 个字符

### Q2: 无法解密已有数据

**错误**: `解密失败`

**解决**:
- 检查 `MASTER_PASSWORD` 和 `ENCRYPTION_SALT` 是否与首次设置一致
- 如果修改过这些值，需要重新初始化用户

### Q3: 路径错误

**错误**: `数据库文件不存在` 或 `日志目录不存在`

**解决**:
- 系统会自动创建目录
- 如果失败，检查文件系统权限
- PythonAnywhere 使用绝对路径，系统会自动调整

### Q4: 数据库迁移

**说明**: 从旧版本升级时，`init.py` 会自动执行必要的迁移

迁移内容包括：
- 添加 `takeover_weekdays` 字段
- 添加 `farewell_message` 字段
- 调整时间字段格式
