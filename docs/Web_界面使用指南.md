# Web 界面使用指南

## 概述

Yunhu-UserAlive v1.2.0 采用 Bootstrap 5 重构了 Web 控制台,提供现代化、响应式的用户界面。

## 访问方式

1. **启动服务器**
   ```bash
   python main.py
   ```

2. **访问控制台**
   - 打开浏览器访问: `http://localhost:5000`
   - 首次使用需要登录

## 页面介绍

### 1. 登录页面 (`/login`)

![登录页面](screenshots/login.png)

**功能**:
- 邮箱和密码输入
- 错误提示显示

- 输入注册时的邮箱和密码
- 点击"登录"按钮进入系统
- 如忘记密码请联系管理员

### 2. 仪表板页面 (`/`)

![仪表板](screenshots/dashboard.png)

**功能模块**:

#### 用户信息卡片
- 显示当前登录用户的邮箱

- **最后签到时间**: 显示上次自动签到的时间
- **刷新按钮**: 手动刷新状态信息

#### 快捷操作卡片
- **系统设置**: 跳转到设置页面
- **查看日志**: (开发中)
- **统计信息**: (开发中)
- **退出登录**: 安全退出系统

#### 使用提示
显示系统的主要功能提示:
- 自动签到时间说明
- 按星期配置托管
- OpenPGP 加密住址
- 电子终别标记

**自动刷新**: 状态信息每30秒自动更新一次

### 3. 设置页面 (`/settings`)

![设置页面](screenshots/settings.png)

设置页面包含四个主要部分:

#### 3.1 自动托管设置

**配置项**:
- ✅ **启用自动托管**: 开关控制是否启用自动签到
- ⏰ **开始时间**: 格式 `YYYY/MM/DD HH:MM:SS`
- ⏰ **结束时间**: 格式 `YYYY/MM/DD HH:MM:SS`
- 📅 **托管日期**: 选择每周哪些天启用托管(周一到周日)

**使用示例**:
```
启用自动托管: ✓
开始时间: 2024/01/01 00:00:00
结束时间: 2024/01/01 06:00:00
托管日期: 周一、周二、周三、周四、周五
```

这样配置后,系统只在工作日的凌晨0点到6点之间执行自动签到。

#### 3.2 电子终别设置

**配置项**:
- ⏱️ **延迟发送时间**: 设置多少小时后发送告别消息(0-720小时)
- 🌍 **全局电子终别标记**: 对所有好友生效

**说明**:
- 设置为0表示立即发送
- 最大可设置720小时(30天)
- 启用全局标记后,所有好友都会收到提醒

#### 3.3 文章链接管理

**添加文章**:
1. 输入文章标题
2. 输入文章URL (格式: `yunhu://post-detail?id=xxx`)
3. 点击"添加文章"按钮

**管理文章**:
- 查看所有已添加的文章列表
- 点击垃圾桶图标删除文章
- 删除前会弹出确认对话框

#### 3.4 好友管理

**添加信任好友**:
1. 输入好友的 Chat ID
2. 输入备注名(可选)
3. 输入 OpenPGP 加密后的住址密文
4. 勾选"局部终别"(可选)
5. 点击"添加好友"按钮

**好友列表**:
显示所有已添加的好友:
- Chat ID
- 名称
- 加密住址(显示前30个字符)
- 局部终别状态
- 删除按钮

**OpenPGP 加密说明**:
- 好友需要先获取您的公钥
- 使用您的公钥加密住址信息
- 将加密后的密文粘贴到表单中
- 详见 [OpenPGP 加密住址使用指南](../docs/OpenPGP_加密住址使用指南.md)

## 常见问题

### Q1: 为什么页面样式加载不出来?
**A**: 确保网络连接正常,Bootstrap 使用 CDN 加载资源。如需离线使用,可以下载 Bootstrap 文件到本地。

### Q2: 状态信息不更新怎么办?
**A**: 
- 检查 WebSocket 连接状态
- 点击"刷新状态"按钮手动刷新
- 查看浏览器控制台是否有错误

### Q3: 移动端显示不正常?
**A**: 
- 清除浏览器缓存
- 尝试横屏/竖屏切换
- 确保浏览器支持现代 CSS

### Q4: 如何自定义主题颜色?
**A**: 修改 `web/templates/base.html` 中的 `<style>` 标签,或创建自定义 CSS 文件。

### Q5: 模板文件在哪里?
**A**: 所有模板位于 `web/templates/` 目录:
- `base.html` - 基础布局
- `login.html` - 登录页面
- `dashboard.html` - 仪表板
- `settings.html` - 设置页面

## 开发者指南

### 添加新页面

1. 在 `web/templates/` 创建新的 HTML 文件
2. 继承 `base.html`:
   ```html
   {% extends "base.html" %}
   
   {% block title %}页面标题{% endblock %}
   
   {% block content %}
   <!-- 页面内容 -->
   {% endblock %}
   ```

3. 在 `web/routes.py` 添加路由:
   ```python
   @app.route('/new-page')
   def new_page():
       return render_template('new_page.html')
   ```

### 自定义样式

在 `base.html` 的 `{% block extra_css %}` 中添加:
```html
{% block extra_css %}
<style>
    .custom-class {
        color: red;
    }
</style>
{% endblock %}
```

### 添加 JavaScript

在模板的 `{% block extra_js %}` 中添加:
```html
{% block extra_js %}
<script>
    // 你的 JavaScript 代码
</script>
{% endblock %}
```
