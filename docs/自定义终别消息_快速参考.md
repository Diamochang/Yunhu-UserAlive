# 自定义终别消息 - 快速参考

## 🚀 快速开始

### 1. 数据库迁移(仅升级用户)
```bash
python migrate_add_farewell_message.py
```

### 2. 测试功能
```bash
python test_farewell_message.py
```

### 3. 启动服务
```bash
python main.py
```

### 4. 访问控制台
浏览器打开: `http://localhost:5000/settings`

---

## 📝 使用方法

### 方法一: Web 界面(推荐)

#### 添加好友时设置
1. 进入设置页面 → 好友管理
2. 填写表单:
   - Chat ID
   - 备注名(可选)
   - OpenPGP加密住址
   - **自定义终别消息**(新增)
   - 勾选"局部终别"
3. 点击"添加好友"

#### 编辑已有消息
1. 在好友列表找到目标好友
2. 点击"自定义消息"列的按钮
3. 在对话框中修改
4. 点击"保存"

#### 清空消息(恢复默认)
1. 点击"编辑"按钮
2. 点击"清空"按钮
3. 确认操作

---

### 方法二: API

#### 设置消息
```bash
curl -X POST http://localhost:5000/api/friend/farewell_message \
  -H "Content-Type: application/json" \
  -d '{
    "friend_chat_id": "12345678",
    "farewell_message": "自定义消息内容"
  }'
```

#### 清空消息
```bash
curl -X POST http://localhost:5000/api/friend/farewell_message \
  -H "Content-Type: application/json" \
  -d '{
    "friend_chat_id": "12345678",
    "farewell_message": null
  }'
```

---

### 方法三: SQL

```sql
-- 设置自定义消息
UPDATE friends 
SET farewell_message = '你的消息'
WHERE user_id = 1 AND friend_chat_id = '12345678';

-- 清空消息
UPDATE friends 
SET farewell_message = NULL
WHERE user_id = 1 AND friend_chat_id = '12345678';
```

## ⚙️ 触发条件

自定义消息显示需要同时满足:
- ✅ 好友发送 **"住址"** 关键词
- ✅ 启用了 **局部电子终别** 标记
- ✅ 好友在信任列表中

## 📏 格式说明

### 支持
- ✅ 纯文本
- ✅ 换行符 (`\n`)
- ✅ Emoji 表情
- ✅ 特殊符号

### 不支持
- ❌ Markdown
- ❌ HTML
- ❌ 富文本

### 建议
- 长度: ≤ 200 字符
- 语言: 温暖积极
- 内容: 个性化但简洁

## 🔧 技术细节

### 数据库字段
```sql
farewell_message TEXT  -- NULL表示使用默认消息
```

### 默认消息
```
⚠️【电子终别】特别提醒：请在信封上写明你的名址，以免失去最后的联系。
```

### API端点
```
POST /api/friend/farewell_message
```

## ❓ 常见问题

**Q: 为什么设置了但不显示?**  
A: 检查是否启用了"局部电子终别"标记

**Q: 可以批量设置吗?**  
A: 目前需逐个设置,可用SQL批量更新

**Q: 会影响性能吗?**  
A: 不会,仅在查询住址时读取

**Q: 如何备份消息?**  
A: 备份整个数据库文件即可

**Q: 消息中有特殊字符怎么办?**  
A: 直接输入,系统自动处理转义
