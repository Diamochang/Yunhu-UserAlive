## 📂 目录说明

### 核心模块

#### `auth/` - 认证模块
负责用户认证和数据加密：
- **crypto.py**: Fernet 对称加密 + bcrypt 密码哈希
- **totp.py**: TOTP 双因素认证

#### `database/` - 数据库模块
管理 SQLite 数据库：
- **models.py**: 表结构定义（users, settings, friends, checkins）
- **db_manager.py**: 数据库操作封装（单例模式）

#### `yunhu/` - 云湖 API 模块
与云湖平台交互：
- **api_client.py**: HTTP API 客户端（登录、获取用户信息）
- **websocket_client.py**: WebSocket 客户端（消息收发、心跳保活）
- **message_handler.py**: 消息处理器（@回复、住址查询）

#### `scheduler/` - 定时任务模块
管理定时执行的任务：
- **tasks.py**: 每日签到、电子终别检查

#### `web/` - Web 控制台模块
提供 Bootstrap 5 现代化界面：
- **routes.py**: Flask 路由和 API 端点
- **templates/**: Jinja2 模板文件
- **static/**: CSS、JS、图片等静态资源

#### `proto/` - ProtoBuf 模块
Protocol Buffers 消息序列化：
- **yunhu.proto**: 完整的 ProtoBuf 定义
- **serializer.py**: 智能序列化器（ProtoBuf ↔ JSON 自动降级）
- **compile.sh**: ProtoBuf 编译脚本

### 部署文件

#### 本地开发
- **app.py**: 主应用入口，启动 Flask + WebSocket + Scheduler
- **start.sh**: 一键启动脚本

#### PythonAnywhere
- **wsgi.py**: WSGI 入口文件（Web 应用）
- **always_on.py**: Always-on 任务入口（后台任务）

#### Docker
- **Dockerfile**: Docker 镜像构建配置
- **docker-compose.yml**: Docker Compose 编排配置

#### 生产环境
- **deploy/nginx.conf**: Nginx 反向代理配置
- **deploy/yunhu-useralive.service**: Systemd 服务配置
- **check_deployment.py**: 部署验证脚本

## 🎯 关键文件说明

### 配置文件

#### `config_local.py.example` (193 行)
**用途**: 统一配置文件示例

**包含内容**:
- 加密配置（MASTER_PASSWORD, ENCRYPTION_SALT, FLASK_SECRET_KEY）
- 数据库配置（DATABASE_PATH）
- 日志配置（LOG_FILE, LOG_MAX_BYTES, LOG_BACKUP_COUNT）
- API 配置（YUNHU_API_BASE_URL, YUNHU_WS_URL）
- 签到配置（CHECKIN_BOT_ID, CHECKIN_GROUP_ID）
- 部署环境（DEPLOYMENT_ENV）
- 云湖账户配置（可选在文件中设置或命令行输入）

**使用方法**:
```bash
cp config_local.py.example config.py
vim config.py  # 编辑配置
```

### 初始化脚本

#### `init.py` (390 行)
**用途**: 交互式初始化向导

**执行步骤**:
1. 检查配置文件（不存在则创建）
2. 验证配置有效性
3. 初始化数据库（创建表结构）
4. 检查并执行数据库迁移
5. 初始化云湖账户（提示输入邮箱和密码）
6. 可选生成安全密钥

**使用方法**:
```bash
python init.py
```

### 应用入口

#### `app.py` (187 行)
**用途**: 本地开发主入口

**功能**:
- 加载配置
- 初始化数据库
- 登录云湖
- 启动 WebSocket 连接
- 启动定时任务
- 启动 Flask Web 控制台

**使用方法**:
```bash
python app.py
```

#### `wsgi.py` (24 行)
**用途**: PythonAnywhere WSGI 入口

**功能**:
- 仅创建 Flask 应用（不启动后台任务）
- 用于 PythonAnywhere Web 应用

**配置**:
在 PythonAnywhere Web 标签页设置 WSGI 文件路径

#### `always_on.py` (238 行)
**用途**: PythonAnywhere Always-on 任务

**功能**:
- 运行 WebSocket 客户端
- 运行定时任务调度器
- 有限时间运行（250秒），避免超时
- 优雅关闭和资源清理

**配置**:
在 PythonAnywhere Tasks 标签页创建定时任务
